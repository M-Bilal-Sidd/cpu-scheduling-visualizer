# ⚙️ CPU Scheduling Visualizer — "Quantum Stealth" Edition

A modern desktop application built with Python and CustomTkinter to simulate and visualize classical CPU scheduling algorithms with interactive Gantt charts and performance metrics.

---

## ✨ Key Features
- **Supported Algorithms:** Visualize First-Come First-Served (FCFS), Shortest Job First (SJF - Non-Preemptive), and Round Robin (RR) scheduling.
- **Animated Gantt Chart:** Sequential left-to-right timeline rendering with auto-scaling time units.
- **Custom UI Architecture:** Built with CustomTkinter featuring custom color interpolation for smooth hover transitions and animated text fade-ins.
- **Performance Metrics:** Automatically calculates Completion Time (CT), Turnaround Time (TAT), and Waiting Time (WT) per process along with average system metrics[cite: 1].
- **One-Click Demo Loader:** Quickly populate pre-configured process sets to demonstrate algorithm differences[cite: 1].

---

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **GUI Framework:** CustomTkinter / Tkinter[cite: 1]
- **Math & Animation:** Python Standard Library (`math`, `time`)[cite: 1]
